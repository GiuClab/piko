## Community post

Title: [Beta testers wanted] Piko Video UI — redesigned video controls for X on Android

I'm maintaining an unofficial Piko fork focused on X's portrait video player. It adds left-side actions, an in-player follow control, double-tap likes, horizontal seeking and a simplified footer.

The latest build has passed compilation and automated tests, and the maintainer reports it working on the development phone. More device coverage is needed. Earlier builds occasionally reported unavailable follow state; please report it if it returns.

Supported X version: 12.19.1-release.0. This is a patch bundle for Morphe, not a ready-to-install X APK.
