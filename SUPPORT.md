# Support

Report bugs specific to this fork in its Issues tab when enabled, not in upstream Piko's tracker by default.

Before reporting, check release compatibility, known issues and existing reports. Use only this fork's Piko source for X.

Include:

- Device model and Android version.
- X, Morphe Manager and patch bundle versions.
- Fresh installation or update.
- Steps to reproduce, expected result and actual result.
- Whether every video or only certain videos/accounts are affected.
- Relevant logs or a short recording, with personal information removed.

Test vertical switching and horizontal seeking separately. For follow problems, include the visible status and exact diagnostic message. Never share credentials, login tokens or signing keys.

If the Issues tab is absent, reporting has not yet been enabled. Do not post sensitive logs elsewhere.
